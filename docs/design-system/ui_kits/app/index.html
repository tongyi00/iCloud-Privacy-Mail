组件文件

整包引入用 components.css（它 @import 下列全部文件）；只要某一类组件时直接引用对应文件。

  • components/app-shell.cssAppShell / Sidebar / 侧栏导航 / 粘性顶栏
  • components/buttons.cssButton 五变体 × 三尺寸，含禁用与焦点环
  • components/cards-panels.cssCard / MetricCard / Panel 容器层
  • components/data-table.cssDataTable / 状态胶囊 / 空态 / 骨架 / 分页 / 窄屏转卡片
  • components/forms.cssField / Input / Switch / Alert / Tabs
  • components/overlays.cssDangerZone / Dropdown / Modal / Log
